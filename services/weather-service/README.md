# Weather Service

Simple Node.js service that provides simulated weather data for the Meridian City platform.

## API Endpoints

- `GET /api/v1/weather` - Get current weather
- `GET /api/v1/weather/forecast` - Get 3-day forecast

## Configuration

- `PORT` - Service port (default: 8096)

## Notes

This is a simulated weather service for demo purposes. In production, you would integrate with a real weather API (e.g., OpenWeatherMap, WeatherAPI).
